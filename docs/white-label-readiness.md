# White-Label Readiness

Lead Ventures / AXIS is the master/default product identity. Tenant branding is isolated in tenant branding/settings records and tenant selection is data-driven; customer names do not control application logic. No FocusQuest, Back2Learn or demo tenant may be compiled into branding decisions.

Before white-label launch, define approved logo formats/sizes, accessible color validation, fallback behavior, email/template branding, asset storage permissions, cache invalidation and custom-domain ownership verification. Custom domains additionally require DNS validation, TLS, redirects, auth/OAuth allowlists, cookie policy, abuse handling and tenant-domain uniqueness. No code fork should be required per tenant.
