# Customer Onboarding

1. Confirm contract, privacy/compliance owners, intended data, geography, contact methods and success criteria.
2. A platform administrator creates the tenant; a tenant administrator verifies default branding and advisory/simulated automation.
3. Add existing authenticated users with least-privilege roles; review the role matrix and remove test access.
4. Configure programs, offers, buyers, caps, routing/recovery policies and approved consent requirements.
5. Register integration metadata; provision credentials only through the trusted server process.
6. Validate field mappings with synthetic records, then import a controlled lead batch and reconcile counts/errors.
7. Import outcomes and verify intelligence, attribution, recovery and recommendation evidence.
8. Train operators on approvals, stale-data warnings, kill switches, circuit breakers, rollback and support escalation.
9. Complete tenant smoke tests and obtain named tenant/Axis approval before controlled traffic.
