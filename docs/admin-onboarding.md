# Administrator Onboarding

Platform administrators provision tenants and platform controls but do not receive implicit PII access. Tenant administrators manage members, registries, integrations and tenant policies but cannot assign `platform_admin`.

Use a distinct authenticated user UUID for each person; assign the minimum tenant role; verify active status; test expected access; record the approval outside sensitive metadata; and schedule access review. Configure buyers/programs/offers before imports, validate integration mappings with synthetic data, keep automation advisory/simulated initially, and review audit/health signals after each change. User invitations, credential provisioning and production environment changes require trusted server/operations procedures—not browser forms.
